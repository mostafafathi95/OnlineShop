# 📋 سیستم سفارشات

## وضعیت‌های سفارش

```
pending      → در انتظار تأیید
processing   → در حال آماده‌سازی
shipped      → ارسال شد
delivered    → تحویل شد
cancelled    → لغو شد
returned     → بازگشت شد
refunded     → بازپرداخت شد
```

## روند سفارش

```
1. ایجاد سفارش
   - اضافه کردن محصولات
   - انتخاب آدرس
   - انتخاب روش ارسال

2. پرداخت
   - انتخاب درگاه
   - تأیید پرداخت
   - ذخیره رسید

3. آماده‌سازی
   - تأیید موجودی
   - بسته‌بندی
   - چاپ لیبل

4. ارسال
   - تحویل به پیک
   - ثبت ترکینگ
   - اطلاع‌رسانی کاربر

5. تحویل
   - دریافت سفارش
   - تأیید کاربر
   - بسته‌شدن سفارش
```

## Return/Refund

```
1. درخواست بازگشت
2. تأیید ادمین
3. دریافت محصول
4. بررسی کیفیت
5. بازپرداخت
```
