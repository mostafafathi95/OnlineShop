# ❌ کدهای خطا و حل

## 2xx Success

```
200 OK - درخواست موفق
201 Created - منبع ایجاد شد
204 No Content - موفق بدون محتوا
```

## 4xx Client Errors

```
400 Bad Request - درخواست نامعتبر
401 Unauthorized - احراز نشده
403 Forbidden - ممنوع
404 Not Found - یافت نشد
409 Conflict - تضاد
422 Unprocessable Entity - نامعتبر
429 Too Many Requests - محدودیت نرخ
```

## 5xx Server Errors

```
500 Internal Error - خطای سرور
502 Bad Gateway - Gateway ناقص
503 Service Unavailable - غیر دسترس
504 Gateway Timeout - Timeout
```

## Custom Error Codes

```
AUTH001 - Invalid credentials
AUTH002 - Token expired
PROD001 - Product not found
ORDER001 - Insufficient stock
PAY001 - Payment failed
DB001 - Database error
```
