# ❓ پرسش‌های متداول

## پروژه

**س: چگونه شروع کنم؟**  
ج: فایل `01_GETTING_STARTED.md` را بخوانید.

**س: مقدار درامدی چقدر است؟**  
ج: بستگی به محصولات و تعداد سفارشات دارد.

**س: چطور تنظیمات تغییر دهم؟**  
ج: Admin Panel > Settings

## فنی

**س: چگونه محصول اضافه کنم؟**  
ج: Admin Panel > Products > Add New

**س: از کدام درگاه پرداخت استفاده کنید؟**  
ج: Zarinpal، Mellat، Parsian، Pasargad، Saman

**س: چگونه backup بگیرم؟**  
ج: `npm run db:backup` یا خودکار هر روز

## مشکلات

**س: صفحه بارگذاری نمی‌شود**  
ج: فایل `17_DEBUGGING_TIPS.md` را بخوانید

**س: خطای دیتابیس**  
ج: `npm run db:push --force` را امتحان کنید

**س: صفحه 404 است**  
ج: URL و routing را بررسی کنید
