# 📦 مدیریت محصولات

## ایجاد محصول

### مرحله 1: معلومات اساسی
- نام محصول (فارسی + انگلیسی)
- توضیح مختصر
- توضیح تفصیلی

### مرحله 2: قیمت‌گذاری
- قیمت فعلی
- قیمت مقایسه
- کد SKU

### مرحله 3: موجودی
- تعداد موجود
- هشدار حداقل موجودی
- وزن

### مرحله 4: رسانه
- تصویر اصلی
- تصاویر اضافی
- ویدیوی معرفی

### مرحله 5: سازمان‌دهی
- دسته‌بندی
- برند
- برچسب‌ها

## ویژگی‌های محصول

```
رنگ: سفید، سیاه، ...
سایز: M، L، XL، ...
ماده: پلاستیک، فلز، ...
```

## تخفیف‌های محصول

```
- تخفیف درصدی
- تخفیف ثابت
- کوپن تخفیف
- خدمات خاص (رایگان‌کاری)
```

## نمایش محصول

```
- صفحه عام (فهرست)
- صفحه جزئیات
- صفحه مقایسه
- محصولات مرتبط
```
